# Registro de decisiones de producto

Usa `docs/product/DECISIONS.md` para decisiones materiales. No registres elecciones triviales de copy o estilo.

```markdown
## DEC-YYYY-MM-DD-NNN — [Título]

**Status**
Active | Superseded | Reversed

**Context**
Qué requería una decisión.

**Decision**
Qué se decidió.

**Reason**
Por qué.

**Alternatives considered**
- ...

**Trade-offs**
Qué se gana y qué se sacrifica.

**Assumptions**
Qué aún no está validado.

**Requirements affected**
- REQ-...

**Supersedes**
DEC-... si aplica.
```
