# Arquitectura

Antes de modificar código, dependencias o límites entre componentes:

1. Lee `docs/architecture.md`.
2. Respeta sus restricciones y las decisiones vigentes de `docs/decisions/`.
3. Si la tarea requiere cambiar la arquitectura, identifica y documenta
   ese cambio antes de implementar las partes que dependen de él.
4. Si falta información necesaria o existen contradicciones, pregunta.
