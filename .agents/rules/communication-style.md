# Estilo de comunicación del agente

- **MUST** mantener las explicaciones concisas, directas y centradas en lo necesario para la tarea.
- **MUST** presentar al final de cada tarea un resumen breve de lo realizado, los ficheros afectados, la validación ejecutada y los pendientes o riesgos relevantes.
- **MUST NOT** añadir contexto, repeticiones o explicaciones que no aporten valor a la solicitud.
- **SHOULD** ampliar el nivel de detalle cuando el usuario lo solicite expresamente o cuando sea necesario para explicar una decisión, un error o una limitación.
