# UPDATE — Actualizar un PRD

Usa este flujo cuando una solicitud o decisión cambia el comportamiento o la intención del producto.

1. Lee el PRD, las decisiones relacionadas y la implementación afectada.
2. Realiza un impacto mínimo: actor, problema, outcome, alcance, flujo, reglas, permisos, datos, UX, analytics, validación, riesgos y preguntas.
3. Modifica solo las secciones afectadas. Preserva los IDs estables y actualiza flujos, reglas, dependencias y criterios relacionados.
4. Clasifica lo nuevo como actual/MVP, posterior, futuro o fuera de alcance. No incorpores oportunidades adyacentes por defecto.
5. Añade supuestos, riesgos y preguntas abiertas relevantes. Registra en `DECISIONS.md` las decisiones materiales y su razonamiento.
6. Actualiza el changelog y relee las secciones afectadas para detectar contradicciones.

Resultado esperado: un PRD actualizado sin pérdida de trazabilidad ni regeneración innecesaria del documento completo.
