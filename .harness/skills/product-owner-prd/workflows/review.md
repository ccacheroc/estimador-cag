# REVIEW — Revisar un PRD

Usa este flujo para evaluar un PRD sin cambiar silenciosamente el comportamiento del producto.

1. Lee el PRD y el contexto mínimo necesario para comprobar sus afirmaciones.
2. Evalúa actor, problema, outcome, alcance, diferenciación, reglas, permisos, estados, criterios de aceptación, métricas, supuestos, riesgos y preguntas abiertas.
3. Comprueba IDs duplicados o renumerados, contradicciones internas, requisitos solution-first, scope creep y comportamiento descrito sin evidencia.
4. Clasifica cada hallazgo por impacto: bloqueante, importante o menor. Incluye ubicación, evidencia, efecto y recomendación.
5. No edites el PRD salvo que el usuario pida convertir la revisión en una actualización.

Resultado esperado: informe de revisión accionable y separado de cualquier decisión de producto aún no confirmada.
