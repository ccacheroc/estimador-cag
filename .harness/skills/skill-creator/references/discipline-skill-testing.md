# Pruebas para skills normativas

Usa este modo cuando una skill exige disciplina, secuencias obligatorias,
verificación o límites que un agente podría racionalizar bajo presión.

## Baseline de presión

Antes de escribir o endurecer la skill, combina al menos tres presiones:

- urgencia o ventana temporal;
- trabajo ya invertido;
- autoridad que pide una excepción;
- coste económico u operativo;
- cansancio;
- presión social para parecer flexible.

Haz que el ejecutor elija y actúe. Evita preguntas académicas y no reveles la
respuesta esperada.

## Evidencia

Registra literalmente la decisión, su justificación, la presión que produjo el
incumplimiento, la sección ignorada y cualquier solución híbrida que eludió la
intención de la regla.

## Endurecimiento mínimo

Para cada fallo observado:

1. aclara el principio protegido;
2. niega la escapatoria concreta;
3. añade la racionalización a una tabla solo si ayuda a reconocerla;
4. incorpora una señal de alarma accionable;
5. repite el escenario y una variante.

No acumules prohibiciones hipotéticas. Las reglas absolutas solo se justifican
por seguridad, permisos, integridad o un fallo demostrado.

## Criterio de éxito

El ejecutor debe cumplir bajo presión, explicar el principio determinante, no
inventar excepciones y mantener el comportamiento en una variante no vista.
